# MM-unity

Unity-based Might and Magic recreation/port project.

This repository tracks the project source, Unity scenes/configuration, editor tooling, scripts, shaders, materials, prefabs, and project-specific world data.

## Required local assets

Large caches, backups, extracted original-game assets, reference packages, and third-party asset packs are intentionally not published in this public repository. They remain local to the development machine and are excluded by `.gitignore`.

The project is a fan/non-commercial effort. No rights to Might and Magic or third-party assets are claimed or granted here.

## Unity

Open the repository root as the Unity project. Unity will recreate `Library/`, `Temp/`, `Logs/`, and other generated folders locally.
